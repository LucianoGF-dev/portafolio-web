# Portfolio Personal

Portafolio personal desarrollado para presentar mi perfil profesional, experiencia, proyectos y habilidades como **Tecnólogo en Informática**.

El sitio funciona como una carta de presentación digital donde se pueden conocer mis proyectos, tecnologías, información de contacto y experiencia en desarrollo web e infraestructura.

**Producción:** [https://luciano-guerrero-portafolio.com](https://luciano-guerrero-dev.vercel.app/)

**Respaldo:** Oracle Cloud Infrastructure (Docker + Nginx Proxy Manager)

## 🏗 Arquitectura de despliegue

El proyecto utiliza una estrategia de despliegue con alta disponibilidad.

### Producción

- Vercel

### Respaldo (Failover)

- Oracle Cloud Infrastructure
- Docker Compose
- Nginx Proxy Manager

Esta configuración permite disponer de una copia funcional del sitio alojada en un servidor propio, facilitando pruebas, mantenimiento y continuidad del servicio ante posibles inconvenientes con el proveedor principal.


Detener los contenedores

```bash
docker compose down
```
